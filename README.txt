ALVEE WORKOUT COACH
====================

This is a phone-installable Progressive Web App (PWA).

Included:
- Original 3-day routine, scheduled twice per week
- Abs A and Abs B, 3 times/week
- 4 x 12 target
- Weight, reps, RIR, form and notes tracking
- Rest timer
- Animated form demonstration and exercise cues
- Offline local storage
- Bodyweight tracker
- JSON backup export

PHONE INSTALL:
1. Put this folder on an HTTPS web host (GitHub Pages, Netlify, Vercel, etc.).
2. Open the HTTPS URL on your Android browser.
3. Choose "Add to Home screen" / "Install app".
4. The app can then run offline after the first load.

IMPORTANT:
A browser cannot install a service-worker PWA directly from a ZIP/file:// URL. It needs HTTPS (or localhost during development).
